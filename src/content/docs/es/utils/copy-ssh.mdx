## ¿Por qué copiar carpetas por SSH?

Cuando trabajas con servidores remotos (especialmente en la nube o VPS), es habitual necesitar:

- Subir el código de una aplicación al servidor
- Descargar logs o backups a tu máquina local
- Sincronizar configuraciones entre entornos

**SSH** no solo sirve para conectarse; también incluye herramientas para transferir archivos de forma segura.

## 1. Usando `scp` (Secure Copy)

### Sintaxis básica

```bash
scp -r carpeta/origen usuario@servidor:/ruta/destino
```

- `-r` : recursivo (necesario para carpetas)
- `-P` : puerto SSH personalizado (si no es el 22)

### Ejemplo 1: Subir carpeta local al servidor

```bash
# Desde tu máquina local
scp -r ~/mi-proyecto alumno@192.168.1.100:/home/alumno/
```

### Ejemplo 2: Descargar carpeta del servidor a local

```bash
# Desde tu máquina local
scp -r alumno@192.168.1.100:/var/log/nginx ~/backups/
```

### Ejemplo 3: Puerto SSH no estándar (ej: 2222)

```bash
scp -P 2222 -r ~/datos/ alumno@servidor.com:~/backups/
```

<Aside type="caution" title="Ojo con la sintaxis">
- `scp` usa `-P` (mayúscula) para el puerto
- `ssh` usa `-p` (minúscula) para el puerto
</Aside>

## 2. Usando `rsync` (más potente)

### Sintaxis básica

```bash
rsync -avz carpeta/origen usuario@servidor:/ruta/destino
```

<table>
  <thead>
    <tr>
      <th>Opción</th>
      <th>Significado</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><code>-a</code></td>
      <td>Modo archivo (preserva permisos, fechas, enlaces simbólicos)</td>
    </tr>
    <tr>
      <td><code>-v</code></td>
      <td>Verboso (muestra lo que copia)</td>
    </tr>
    <tr>
      <td><code>-z</code></td>
      <td>Comprime durante la transferencia</td>
    </tr>
    <tr>
      <td><code>-P</code></td>
      <td>Muestra progreso y permite reanudar</td>
    </tr>
    <tr>
      <td><code>--delete</code></td>
      <td>Borra en destino lo que no existe en origen</td>
    </tr>
  </tbody>
</table>

### Ejemplo 1: Subir carpeta con progreso

```bash
rsync -avzP ~/mi-proyecto/ alumno@servidor:~/mi-proyecto/
```

<Aside type="note" title="Barra final importante">
`~/mi-proyecto/` con barra copia el **contenido** de la carpeta.  
`~/mi-proyecto` sin barra copia la **carpeta entera**.
</Aside>

### Ejemplo 2: Sincronizar bidireccionalmente (solo cambios)

La segunda vez que ejecutes el mismo comando, `rsync` solo copiará los archivos modificados.

```bash
rsync -avz ~/proyecto/ usuario@servidor:~/proyecto/
```

### Ejemplo 3: Descargar carpeta completa

```bash
rsync -avzP alumno@servidor:/var/log/ ~/logs-servidor/
```

### Ejemplo 4: Sincronizar eliminando archivos huérfanos

```bash
rsync -avz --delete ~/local/ usuario@servidor:/remoto/
```

## 5. Ejemplos prácticos para el LFCS

### Subir una web completa al servidor

```bash
rsync -avz --delete ~/mi-web/ alumno@servidor:/var/www/html/
```

### Descargar logs de acceso para analizar localmente

```bash
scp -r alumno@servidor:/var/log/nginx/ ~/analisis-logs/
```

### Hacer backup semanal de configuración

```bash
rsync -avz /etc/ alumno@backup-server:/backups/etc-fecha/
```

### Copiar desde un servidor con autenticación por clave

```bash
# Primero configurar clave SSH (ver práctica 1, paso 4)
scp -i ~/.ssh/mi-clave-privada -r carpeta/ usuario@servidor:/destino/
```

## 7. Bonus: copiar una carpeta manteniendo permisos

```bash
# Con rsync (recomendado)
rsync -avz --chown=usuario:grupo carpeta/ usuario@servidor:/destino/

# Con scp (no preserva permisos igual que rsync)
scp -rp carpeta/ usuario@servidor:/destino/
```

<Aside type="tip" title="Alias útiles">
Añade estos alias a tu `~/.bashrc` para transferencias rápidas:

```bash
alias subir='rsync -avzP'
alias bajar='rsync -avzP'
alias copia-segura='rsync -avz --delete'
```
</Aside>

## Resumen de comandos

```bash
# Subir carpeta con scp
scp -r local/carpeta usuario@servidor:/remota/

# Subir carpeta con rsync (recomendado)
rsync -avzP local/carpeta/ usuario@servidor:/remota/

# Descargar carpeta del servidor
rsync -avzP usuario@servidor:/remota/carpeta/ local/

# Sincronización bidireccional (sube solo cambios)
rsync -avzP local/ usuario@servidor:/remota/
```
