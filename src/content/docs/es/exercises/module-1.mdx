## Objetivo

Al terminar esta práctica tendrás un servidor Ubuntu Server 24.04 corriendo y accesible por SSH desde tu ordenador, igual que un servidor remoto real. Elige el método que mejor se adapte a tu sistema.

</Aside>

## Paso 1 — Levantar el servidor

<Tabs>
<TabItem label="Linux (Distrobox)">

**Un solo comando:**

```bash
distrobox create --name servidor-linux --image ubuntu:22.04 && distrobox enter servidor-linux
```

<Aside type="note" title="¿Ya lo tienes instalado?">
Si no tienes Distrobox: `sudo pacman -S distrobox podman` (Arch) o `sudo apt install distrobox podman` (Debian/Ubuntu)
</Aside>

</TabItem>
<TabItem label="Windows (WSL2)">

**Un solo comando (PowerShell como admin):**

```powershell
wsl --install -d Ubuntu-24.04
```

<Aside type="note" title="Después de instalar">
Reinicia el PC. Al abrir "Ubuntu 24.04" desde el menú, crea usuario `alumno` y contraseña.
</Aside>

</TabItem>
<TabItem label="Mac (Lima)">

**Dos comandos:**

```bash
brew install lima
limactl create --name=servidor-linux template://ubuntu && limactl shell servidor-linux
```

</TabItem>
</Tabs>

## Paso 2 — Primera sesión en el servidor

<Tabs>
<TabItem label="Linux (Distrobox)">

Ya estás dentro (ejecutaste `distrobox enter` en el paso anterior). Si saliste, vuelve a entrar:

```bash
distrobox enter servidor-linux
```

</TabItem>
<TabItem label="Windows (WSL2)">

Ya estás dentro. Si cerraste la ventana, vuelve a abrir Ubuntu desde el menú Inicio o ejecuta:

```powershell
wsl -d Ubuntu-24.04
```

</TabItem>
<TabItem label="Mac (Lima)">

Ya estás dentro. Si saliste, vuelve a entrar:

```bash
limactl shell servidor-linux
```

</TabItem>
</Tabs>

**Una vez dentro, ejecuta estos 4 comandos:**

```bash
uname -a                    # Ver información del sistema
ip addr show                # Ver redes
sudo apt update             # Actualizar lista de paquetes
sudo apt upgrade -y         # Instalar actualizaciones
```

<Aside type="tip" title="¿Te pide contraseña?">
Escribe la que pusiste al crear el usuario (no se ve mientras escribes). Es normal.
</Aside>

## Paso 3 — Conectarte por SSH

<Tabs>
<TabItem label="Linux (Distrobox)">

**No necesitas SSH.** Distrobox ya te mete dentro de Ubuntu directamente. Si quieres practicar SSH igualmente:

```bash
# Dentro de Ubuntu, instalar SSH y obtener IP
sudo apt install -y openssh-server
ip addr show | grep inet
```

Luego desde otra terminal de Arch: `ssh alumno@<IP>`

</TabItem>
<TabItem label="Windows (WSL2)">

**No necesitas SSH.** Ya estás dentro de Ubuntu. Si quieres practicar:

```powershell
# Desde PowerShell, obtener IP y conectar
wsl hostname -I
ssh alumno@<IP-WSL>
```

</TabItem>
<TabItem label="Mac (Lima)">

**No necesitas SSH.** Lima ya te mete dentro. Si quieres practicar:

```bash
# Dentro de Ubuntu, ver IP
ip addr show | grep inet
# Desde otra terminal: ssh alumno@<IP>
```

</TabItem>
</Tabs>

<Aside type="tip" title="¿Para qué sirve SSH?">
En un servidor real trabajarías por SSH. Aquí, como el servidor está en tu mismo ordenador, puedes entrar directamente. El objetivo es que aprendas el comando `ssh`.
</Aside>

## Paso 4 — Autenticación por clave SSH *(opcional)*

<Aside type="tip" title="¿Para qué sirve?">
Para no escribir la contraseña cada vez que te conectas por SSH. Es el estándar en servidores reales.
</Aside>

<Tabs>
<TabItem label="Linux (Distrobox)">

**Generar clave (en Arch, fuera del contenedor):**

```bash
ssh-keygen -t ed25519 -C "alumno@clase"
# Pulsa Enter 3 veces
```

**Copiar clave al servidor:**

```bash
ssh-copy-id alumno@<IP-del-contenedor>
```

**Verificar:**

```bash
ssh alumno@<IP>  # Ya no pide contraseña
```

</TabItem>
<TabItem label="Windows (WSL2)">

**Generar clave (en PowerShell):**

```powershell
ssh-keygen -t ed25519 -C "alumno@clase"
# Pulsa Enter 3 veces
```

**Copiar clave al servidor:**

```powershell
type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh alumno@<IP-WSL> "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
```

**Verificar:**

```powershell
ssh alumno@<IP-WSL>  # Ya no pide contraseña
```

</TabItem>
<TabItem label="Mac (Lima)">

**Generar clave:**

```bash
ssh-keygen -t ed25519 -C "alumno@clase"
# Pulsa Enter 3 veces
```

**Copiar clave al servidor:**

```bash
ssh-copy-id alumno@<IP-del-contenedor>
```

**Verificar:**

```bash
ssh alumno@<IP>  # Ya no pide contraseña
```

</TabItem>
</Tabs>

<Aside type="note" title="¿No tienes IP?">
Dentro de Ubuntu ejecuta `ip addr show` y busca una IP que empiece por `172.` o `192.168.`
</Aside>

---

## Paso 5 — Configurar el hostname y la zona horaria

```bash
# Cambiar el hostname (nombre del servidor)
sudo hostnamectl set-hostname servidor-linux

# Configurar la zona horaria a España
sudo timedatectl set-timezone Europe/Madrid

# Verificar
timedatectl
```

### 2. Estructura de carpetas

Dentro del repositorio, cada práctica tiene su propia carpeta. La estructura es **siempre la misma**:

```
lfcs-practicas/
├── practica1/
│   ├── README.md
│   └── entrega/
│       └── verificacion.txt
├── practica2/
│   ├── README.md
│   └── entrega/
│       ├── verificacion.txt
│       └── (otros ficheros si los hay)
├── practica3/
│   ├── README.md
│   └── entrega/
│       └── ...
...
└── practica6/
    ├── README.md
    └── entrega/
        ├── verificacion.txt
        └── (ficheros específicos del ejercicio)
```

<Aside type="note" title="Regla de oro">
**Todo lo que se pide guardar** en cada ejercicio debe ir dentro de `practicaX/entrega/`.
El `README.md` explica **qué hiciste, cómo y qué problemas tuviste**.
</Aside>


### 7. Ejemplo completo para la Práctica 1

**Dentro del servidor Ubuntu (Distrobox/WSL/Lima):**

```bash
# Crear estructura
mkdir -p ~/lfcs-practicas/practica1/entrega

# Generar verificacion.txt
{
  echo "=== ENTREGA PRÁCTICA 1 ==="
  echo "Hostname: $(hostname)"
  echo "Usuario: $(whoami)"
  uname -a
  ip addr show | grep "inet " | grep -v "127.0.0.1"
  timedatectl | grep "Time zone"
  sudo apt list --upgradable 2>/dev/null | wc -l
} > ~/lfcs-practicas/practica1/entrega/verificacion.txt

# Crear README
cat > ~/lfcs-practicas/practica1/README.md << 'EOF'
# Práctica 1 — Instalación y Entorno

## Servidor utilizado
- Método: Distrobox
- SO: Ubuntu 22.04 LTS
- Hostname: servidor-linux

## Comandos aprendidos
- `distrobox create` - crear contenedor Ubuntu
- `sudo apt update && sudo apt upgrade` - actualizar sistema
- `hostnamectl` - cambiar nombre del servidor
- `timedatectl` - cambiar zona horaria

## Dificultades
Al principio no distinguía si estaba dentro de Ubuntu o en Arch. Lo solucioné ejecutando `cat /etc/os-release`.

## Tiempo
45 minutos

## Evidencia
La carpeta `entrega/` contiene la verificación del sistema.
EOF

# Inicializar git y subir
cd ~/lfcs-practicas
git init
git add .
git commit -m "Entrega práctica 1: servidor Ubuntu con Distrobox"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/lfcs-practicas.git
git push -u origin main
```
